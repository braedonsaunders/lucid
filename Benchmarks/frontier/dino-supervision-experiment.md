# Adaptive hierarchical feature supervision

The official [PixRestore repository](https://github.com/csslc/PixRestore) was located and reviewed at `909ca06e614cf72e218d52b4fa41077c603d872b`. Its August 17, 2026 release implements pixel-space diffusion, DINO-based conditioning and reverse-reliability-weighted hierarchical supervision. Lucid adapts only the training supervision idea. It does not implement or claim to reproduce the complete PixRestore architecture, diffusion training or DINO-GAN refinement.

`Tools/experiments/dino_supervision.py` uses the official DINOv2 ViT-S/14 backbone from a clean local [Meta checkout](https://github.com/facebookresearch/dinov2) pinned to `7764ea0f912e53c92e82eb78a2a1631e92725fc8`. DINOv2 is an older backbone; the August 2026 contribution being tested is adaptive hierarchical supervision, not a claim that DINOv2 itself is new. Its Apache-2.0 code and official weights remain separate training dependencies. The downloaded weights have SHA256 `b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9` and size 88,283,115 bytes. The loader checks the repository revision, clean tracked content and exact weight hash before use.

Six intermediate layers (1, 2, 4, 6, 8, 10) supply patch features. Low-quality/reference cosine similarity defines detached per-image layer weights through `softmax((1-similarity)/temperature)`, emphasizing less reliable layers. The reconstruction receives weighted cosine supervision toward reference features. Input normalization is ImageNet RGB; bicubic resizing uses a recorded 224-pixel feature grid, rather than the paper's 448-pixel configuration. Targets, weights and encoder parameters stay frozen; gradients flow to reconstructed pixels. One frame per training sequence is selected deterministically by step modulo sequence length to control teacher cost. No encoder, router or additional inference parameters enter the Mac graph.

Two unit tests verify weighting direction and gradient isolation. A real-weight CPU probe confirms finite nonzero image gradients and no encoder gradients. A full two-step trainer smoke verifies initialization from a v2 checkpoint, feature supervision, backpropagation, validation and checkpoint serialization.

`causal-dino-training-command.ps1` defines a CUDA smoke followed by two matched 4,000-step fine-tunes from the same completed v2 checkpoint, using the frozen original bank, seed 20260908, learning rate 0.00002, batch four, 96-pixel LR crops and the same sequence curriculum. The candidate adds feature weight 0.03; the control does not. The script refuses preexisting Python jobs and output directories and checks again between runs. It does not claim a quality gain before independent scoring. V2's source-specific flicker failures remain an explicit guardrail.
