# FiDeSR teacher screen — fixed before GPU evaluation

The existing PixRestore output improves perceptual distances while losing fine detail against shipping. [FiDeSR, CVPR 2026](https://github.com/Ar0Kim/FiDeSR), releases a different one-step diffusion model with latent residual refinement and frequency-dependent enhancement. Its actual released model is worth testing as an alternative teacher before any additional distillation. A recent title is not evidence it will win this streaming-video domain.

Source inspection found that the released low-pass grid uses unsigned full-height indices and half-width indices instead of consistent signed FFT frequency coordinates. Executing that exact function on a 64×64 cosine with three cycles gives amplitude gains 0.83814 horizontally and 0.49388 vertically at the prescribed cutoff/order. The adjacent frequency diagnostic records this orientation dependence. The official baseline retains it; this diagnostic is not evidence of the model's image quality, and no filter change is selected from development results.
